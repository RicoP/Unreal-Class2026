### BS_Enemy_Base (Blend Space1D)

Create a new Blend Space1D named `BS_Enemy_Base` in `/Game/App/Enemy`, then set:

| Setting | Value |
|---|---|
| Sample Data: add | character-female-aidle at Beginning of Blend |
| Sample Data: add | character-female-awalk at End of Blend |
| Blend Parameters[0] › Display Name | Walk Speed |
| Blend Parameters[0] › Max | 450.000000 |
| Skeleton | character-female-a_Skeleton |
