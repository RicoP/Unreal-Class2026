### BP_Enemy_Base (Blueprint Class)

Create a new Blueprint Class named `BP_Enemy_Base` in `/Game/App/Enemy`, then set:

| Setting | Value |
|---|---|
| Parent Class | Character |
| Class Defaults › Auto Possess AI | Placed In World Or Spawned |
| Character Movement › Max Walk Speed | 450 |
| Character Movement › Orient Rotation To Movement | True |
| Mesh › Skeletal Mesh Asset | TutorialTPP |
| Mesh › Relative Location | X: 0, Y: 0, Z: -90 |
| Mesh › Relative Rotation | Pitch: 0, Yaw: 270, Roll: 0 |
